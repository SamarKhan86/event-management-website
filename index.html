About WAYFARER

A purposeful web designing project marrying atmospheric aesthetics with modern usability.

Project Overview & Architecture

WAYFARER was developed for the K Explore — Web Designing curriculum assignment. The application is built entirely with semantic HTML5, responsive CSS3, and vanilla JavaScript (ES Modules), demonstrating solid foundational web development without heavy frameworks or bloated dependencies.

The event catalogue features a hybrid composition: four verified academic conferences officially hosted by KIIT Deemed to be University alongside five curated demonstration concepts reflecting creative technology, indie gaming, and pop culture.

Features include live combined search and category filtering, responsive layouts across mobile, tablet, and desktop viewports, live event countdown timers, client-side input validation, and browser-local demo registration persistence.
